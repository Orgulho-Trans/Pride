## 🏳️‍⚧️ Bandeira Trans – Orgulho em Cores!

A bandeira trans representa:

- **Azul claro** → bebês designados meninos  
- **Rosa** → bebês designados meninas  
- **Branco** → pessoas não-binárias, intersexo, transição ou gênero fluido
